# @siddhartha/mcp-shield

## 0.1.0-alpha.0

### Minor Changes
- Initial release of `mcp-shield`. Includes:
  - SSRF Guard
  - Rate Limit Guard
  - CORS Guard
  - Input Validator (depth/size)
  - Prompt Injection Scanner
  - Command Execution Sandbox
  - Secrets Redactor
  - Core Shield Middleware Composer with `strict`, `balanced`, and `permissive` presets.
